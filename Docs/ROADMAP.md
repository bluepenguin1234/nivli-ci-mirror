# Roadmap

## 3.0 (this build) — the accountability app

Lock the apps you chose until you have moved. Manual log or Apple Health. Streaks, rest
days, one subscription. No account, no server. This is the product.

## Considered and declined (16 Sep 2026)

**A social layer** (post a photo after a workout, friends give props, a feed like a running
platform). Discussed and set aside by the owner the same day: Nivli stays a personal
accountability app. For the record, it would need accounts (Sign in with Apple), a backend
for photos and a feed, Apple's user-generated-content rules (report, block, moderation,
in-app account deletion) and a changed privacy label, so it is a separate product decision,
not a feature.

## Small things worth doing after 3.0 ships

- A 7-day free trial as an introductory offer (App Store Connect only; the paywall already
  shows it).
- A Home Screen widget with the ring and the streak.
- Exporting the workout log as CSV from Settings.
